# Leaderboard Service

## Overview
Read-optimized rankings filtered by timeframe

## Port
Default port: `8086`

## Scripts
- `pnpm dev` : Runs the service locally with Go
- `pnpm build` : Compiles the Go binary to `bin/server`
- `pnpm test` : Runs Go tests
- `pnpm lint` : Runs Go static analysis (`go vet`)
